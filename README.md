# Digital Contact Book

A simple Python project for keeping and managing a list of contacts.

## Features

- Add contacts
- View all contacts
- Search by name, phone or group
- Create groups
- Mark favorites
- Edit contacts
- Delete contacts
- Show simple statistics
- Export contacts to a text file
- Add sample contacts for testing
- Clear the contact list
- Save data using JSON

## Run in VS Code

```bash
python digital_contact_book.py
```

Windows can also use:

```bash
py digital_contact_book.py
```

## Python topics used

Functions, dictionaries, lists, loops, conditions, JSON, file handling, `try/except`, input validation and string operations.

This is an educational console project.
